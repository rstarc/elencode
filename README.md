# elencode - Coding Agent in Go

This is a toy project for fun and learning for now.

Initially, I set out to build a "test driven development" coding agent. 
However, I increasingly think that there is little value in this, since simply telling most models 
to "use red/green TDD" already does most of what I would otherwise rigidly enforce in the harness.

So for now, this is a minimalistic, and therefore opiniated coding agent, just for me.
